The docket

Four outcomes. Never a maybe.

No probabilistic scoring, no confidence interval, no semantic judgment — every predicate is a deterministic equality check against independently observed state.

Positioning

What this is, and isn't

AgentProof is

  • An independent verifier. A separate credential, a separate re-query, a separate verdict — never a read of the agent's own tool-call result.
  • Deterministic. Every predicate is a literal equality check. No confidence scores to argue with.
  • Evidence-first. Every verdict ships with the full trail — what was checked, when, with which credential.

AgentProof is not

  • Observability or a logging dashboard.
  • A testing or eval framework for prompts.
  • An orchestration engine, guardrail layer, or agent framework.
